**First public release of TradingAutoTV**
- Reads your open TradingView Desktop / Chrome / Edge chart directly (strategy orders, shapes, text labels, lines, zones…) — no alerts, no webhooks.
- 5-step bot wizard: open / close BUY and SELL conditions; SL / TP preset or from the chart, several TP levels by %, trailing, break-even after TP1; fixed or risk-based lots.
- Magic number and comment per bot to filter and group orders in MT5.
- New bots always start in WATCH ONLY; a wrong layout / account pauses new orders but still closes existing ones; bots restart when the app reopens.
- Many MT5 accounts, each with a clean hidden terminal; a broker not yet on the computer needs one manual login; remove accounts from the app.
- Binance USDⓈ-M Futures (new): testnet or live, SL / TP placed on the exchange.
- Signed self-updates with automatic rollback if a new version fails to start. Vietnamese / English interface.
